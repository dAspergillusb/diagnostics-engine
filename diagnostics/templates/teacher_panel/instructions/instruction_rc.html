Вы находитесь в конструкторе для учителя. Предмет — Читательская грамотность, {{ school_class }} класс. Здесь вам необходимо создать 15 вопросов (тест целиком) для последующей генерации их в тестах диагностик. Во вкладке "Конструктор теста" находятся поля для заполнения. Первый из них — название теста, далее текст, по которому будут составлены 15 вопросов. Все вопросы являются обязательными!

 По окончании заполнения обязательных полей нужно нажать на кнопку "Сохранить вопросы".

 Обязательные для заполнения поля:

  1. Название теста;

  2. Текст, по которому будут вопросы;

  3. Текст или картинка для конкретного вопроса (по отдельности или оба сразу);

  4. Вариант(ы) ответов. Если вы подразумеваете несколько вариантов, то необходимо также заполнить и сами варианты.

 Если вы хотите создать вопрос только с текстом (без изображения), то нужно поле для картинки оставить пустым. Если вопросом является само изображение, то текст нужно оставить пустым, а в поле для изображения прикрепить файл-изображение. Поддерживаемые типы изображений: .jpg, .jpeg, .png, .svg.
