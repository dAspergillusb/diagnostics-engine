Общая информация

 Добро пожаловать в конструктор вопросов для тестов диагностик. Здесь вы можете добавлять как один вопрос для конкретного класса по своему предмету, так и весь тест целиком. Для 2-4-х в конструкторе можно добавить до 8-и вопросов классов 5-6-х — 12 вопросов, для 7-9 — 16 вопросов, для 10-11 — 20 вопросов. Каждый вопрос находится в отдельной ячейке для удобной навигации между ними.

 Давайте познакомимся с интерфейсом конструктора и разберёмся с тем, как создавать отдельные вопросы или тесты целиком, и чтобы не возникало ошибок при создании.

 Во-первых, если посмотреть на навигационную панель сверху, то там можно найти слова "Информация", "Класс" и ваше имя и фамилию, указанные при регистрации. Первая опция служит для того, чтобы вы могли выбирать предмет, по которому собираетесь создать вопрос (или тест целиком), вторая — для выбора класса, третья — панель для пользователя. На изображениях ниже показаны выпадающие списки предметов, классов и содержимое панели пользователя:

 Для конкретного учителя список предметов будет своим (зависит от того, какие предметы учитель выбрал при регистрации). В выпадающем списке классов появляются лишь те, начиная с которых конкретный предмет вводится в нагрузку. Для того чтобы отобразились предметы или классы, нужно кликнуть левой кнопкой мыши на соответствующей кнопке. В первую очередь необходимо выбрать предмет, а потом класс. Только тогда вы попадёте в нужное меню!

Для того чтобы начать разрабатывать вопрос(ы), нужно перейти во вкладку с номером вопроса, который вы хотите добавить и в правой части заполнять необходимые поля для вопроса. Красным цветом выделены обязательные к заполнению поля, зелёным цветом — одно необходимо заполнить (можно оба сразу).

Вместо заключения

 Таким образом в конструкторе учителя следует разрабатывать вопросы для тестов. По завершении разработки необходимо нажать на кнопку Сохранить вопрос внизу страницы если вы создали только один вопрос. Если же вы создали более одного вопроса, о вам необходимо во вкладке последнего вопроса нажать на кнопку Сохранить все вопросы. Система автоматически выберет заполненные вами вопросы и сохранит их в базу данных.

 Спасибо за использование системы диагностик. Вы помогаете нам становиться лучше!
