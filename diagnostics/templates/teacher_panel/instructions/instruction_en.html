Здесь вы можете создать до {{ _range[-1] }} блоков вопросов (или все сразу) для последующей генерации их в тестах диагностик. Конечное количество блоков зависит от класса. Для 7-го их четыре, а для 11-го — десять. Во вкладках "Блок вопросов" находятся поля для заполнения.

 1. Название для блока;

 3. Поле для загрузки аудио-файла;

 3. Поле для ввода первого вопроса, а также хотя бы один вариант ответа.

 Второй блок всегда для вопросов по тексту. Внутри этого блока содержится поле для названия, ввода текста и до десяти вопросов. Каждый вопрос содержит в себе текст вопроса, возможные ответы (если они есть) и правильный ответ. Для данного блока обязательными являются поля:

 1. Название для блока;

 2. Текст, по которому буду вопросы;

 3. Поле для ввода первого вопроса, а также хотя бы один вариант ответа.

 Все остальные блоки для вопросов на разные темы. В каждом блоке содержится по десять вопросов. Внутри каждого вопроса есть возможность заполнить текст вопроса или/и приложить изображение, варианты ответов, а также правильные ответы. Обязательными для заполнения полями являются:

 1. Название для блока;

 2. Текст, по которому буду вопросы или/и приложенное изображение;

 3. Поле для ввода первого вопроса, а также хотя бы один вариант ответа.

 По окончании заполнения каждого блока нужно нажать на кнопку "Сохранить блок вопросов".

 Обратите внимание, что нет необходимости заполнять все десять вопросов в блоке. Достаточно одного вопроса, но имеет смысл заполнить хотя бы пять вопросов.

 Для третьего и тд блоков, если вы хотите создать вопрос только с текстом (без изображения), то нужно поле для картинки оставить пустым. Если вопросом является само изображение, то текст нужно оставить пустым, а в поле для изображения прикрепить файл-изображение. Поддерживаемые типы изображений: .jpg, .jpeg, .png, .svg.
